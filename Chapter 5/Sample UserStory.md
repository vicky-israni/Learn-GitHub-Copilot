# User Story

**As** Vicky
**I want** to access a webpage for registration and login
**So that** I can create an account and access the system

## Acceptance Criteria

1. **Registration Form:**
   - I can see a registration form with fields for:
     - Name
     - Email
     - Phone number
     - Profile picture upload
     - Password
   - I receive confirmation upon successful registration

2. **Login Form:**
   - I can see a login form with:
     - Email field
     - Password field
   - I can successfully log in with my credentials
   - I receive appropriate error messages for invalid credentials

3. **Security:**
   - My password is stored securely using encryption
   - My session remains active until I logout
   - I can recover my password if forgotten

## Story Points
8

## Priority
High

## Dependencies
- Database setup for user management
- Security infrastructure for password encryption
