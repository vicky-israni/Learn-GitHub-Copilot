# Learn GitHub Copilot

This repository contains the codebases, examples, exercises, and supporting files referenced in the book **Learn GitHub Copilot**.

**Author:** Vicky Israni  
**Book:** Learn GitHub Copilot

## About This Repository

The repository is organized by chapter so readers can follow along with the book and explore the corresponding source code. The examples cover several languages and technologies, including Python, Java, JavaScript, React, SQL, OpenAPI, testing, security, and policy configuration.

## Repository Structure

- `Chapter 1` through `Chapter 17` contain the examples and supporting material for their respective chapters.
- Individual chapter folders may include source code, tests, requirements, configuration files, or sample project structures.

## Using the Examples

1. Clone or download this repository.
2. Open the folder for the chapter you are reading.
3. Review any chapter-specific README, requirements, or configuration files.
4. Run the examples using the tools and dependencies described in the book.

Some examples are intentionally incomplete or contain issues so that readers can practice using GitHub Copilot to generate, explain, test, debug, and improve code.

## Disclaimer

This repository is intended for learning and demonstration purposes. Review and test the examples before using them in production environments.
